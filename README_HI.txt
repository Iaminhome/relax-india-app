RELAX INDIA - मोबाइल ऐप प्रोटोटाइप

इस ZIP में:
- www/index.html : ऐप की स्क्रीन (वेबसाइट डेमो)
- package.json : प्रोजेक्ट निर्भरताएँ
- capacitor.config.json : Android/iOS wrapper configuration

महत्वपूर्ण:
यह अभी install करने योग्य APK/IPA नहीं है। यह शुरुआती फ्रंट-एंड प्रोटोटाइप और Capacitor प्रोजेक्ट बेस है।
Android APK बनाने के लिए कंप्यूटर पर Node.js और Android Studio की जरूरत होगी:
1) ZIP extract करें
2) npm install
3) npx cap add android
4) npm run build
5) npx cap sync android
6) npx cap open android
फिर Android Studio में परीक्षण करके signed APK/AAB बनाएं।

iOS ऐप बनाने के लिए macOS और Xcode की जरूरत होगी।
लाइव लॉन्च से पहले backend, सुरक्षित login/OTP, booking database, payment gateway,
provider verification, support, refund, privacy policy और कानूनी समीक्षा जरूरी है।
सभी सेवा प्रदाता 18+ और उचित प्रशिक्षण/योग्यता वाले होने चाहिए।
